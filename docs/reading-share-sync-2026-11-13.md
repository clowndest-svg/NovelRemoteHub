# 1.10.0 同步修复与只读阅读分享

## 同步规则

本地 `D:\小说` 下各作品的正文与设定作为同步依据。每五秒独立扫描实际内容摘要，创作任务执行期间继续扫描。每分钟上传完整快照复核云端，首页也可请求立即同步。失败上传和失败回执持续重试，只有云端落盘内容的 SHA256 摘要与本地一致才确认成功。

同步覆盖新增、修改、改名与单文件移除。云端多余的章节、设定移入作品 `.sync-archive` 目录，保留恢复副本。隐藏备份目录排除在章节目录和书架计数之外。整个本地作品目录移除后的云端整书清理由作者另行处理。

同步状态记录最近成功时间与错误信息，电脑离线时显示等待上线。手动同步通过独立心跳通知桥接器，正常网络下通知周期至多十秒，再由五秒同步周期处理。网络失败持续重试，完成时间受上传耗时影响。

## 阅读分享

管理页新增“分享阅读”，可生成、复制并打开链接。一个链接允许浏览全部有正文的已同步作品，也能看到有效期内新增的同步章节。读者按小说书架、章节目录、正文逐级浏览，可搜索书名与章节、调整字号、切换前后章以及使用浏览器返回。

链接生成起七天有效，每次重新生成得到独立链接，既有链接沿用原到期时间。用途隔离的 HMAC 签名由服务端逐次校验。链接凭据放在 URL 片段，阅读请求通过专用请求头传入。未登录读者仅能访问书架、目录与正文，作品对象省略本地路径及设定信息。读者凭据访问管理接口与写操作会被拒绝。链接过期时阅读页清空已显示的正文与目录，并提示向作者索取新链接。

## 查询优化

首页通过一个合并接口取得书架、目录和最新正文。模型列表独立加载，阅读加载完成后即可使用。短期复用刚取得的正文，章节元数据按文件版本复用。一次同步集中失效受影响的作品缓存。分享页面的深链首次访问并发取得目录与正文，正常前后章切换复用短期目录。

## 发布记录

生产发布前备份位于服务器 `/opt/novel_hub_backups/pre-1.10.0-20261113.tar.gz`。发布前记录了 40 份正文与设定的逐文件摘要，隔离环境测试通过后替换应用文件。

线上验收结果已全部完成闭环：
- 生产环境首屏正文加载用时从约 6.9 秒优化提升至 2.9 秒（实测延迟：6920ms -> 4275ms -> 2901ms），彻底解除了首屏对外部模型列表串行阻塞的等待。

- 线上正式生成 7 天有效只读阅读链接，实测通过三级流式访问（书架 -> 目录 -> 正文），并已实测校验权限沙箱防线：未授权的管理端操作、设定集读取及创作任务提交均被正确拦截（HTTP 401/403）。
- Android 1.10.0 APK 构建与对齐签名校验已通过并发布至云端下载目录；因当前无可用真机设备，实体机真机交互暂留待后续环境具备时实测验证。
