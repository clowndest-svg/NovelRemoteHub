## 优先修复

| 顺序 | 实际问题 | 实施及验收 |
| --- | --- | --- |
| 1 | 同步和进度接口未鉴权，图片路径可越界，固定公开令牌 | 统一写接口鉴权、服务端持久随机令牌、桥接私有配置、路径边界和输入大小校验。验证未授权请求和越界请求被拒绝 |
| 2 | 完成任务调用 Redis FLUSHDB，影响共用服务 | 缓存仅使用 novel 专属前缀，以 SCAN 清理自身键。验证其他业务键保留 |
| 3 | 单线程 HTTP 阻塞、文件原地覆盖、并发任务更新无保护 | 有限并发 HTTP、原子文件替换、写操作锁、任务领取与持久化一致。验证并发查询、重启恢复和损坏 JSON 保护 |
| 4 | Antigravity 重启后缺少语言服务地址与 CSRF，CLI 成功退出未必代表任务完成 | 自动发现当前有效 hub，检查结构化错误，等待会话执行结束和文件成果，任务心跳与失败状态完整回传 |
| 5 | 插画只是 PIL 文字模板，固定仙秦剧情串入其他章节 | 实际通过 Antigravity 图像工具按当前章节绘制 1–4 张二维水墨场景。独立生成目录和完整性校验后切换元数据，保留旧成果。生成失败返回可读错误 |
| 6 | 作者有话说绑定绘图、章评没有独立字段、无法编辑保存 | 独立文案生成，作者有话说与章评分开编辑、保存、复制、导出。校验章节归属和保存版本，防止覆盖其他页面正在编辑的文案 |
| 7 | 查询重复、跨书跨章响应串页、机审数据映射错误 | 请求去重及超时、按书籍和文件缓存、异步响应归属检查、内容变化失效、正确读取 audit 内部指标 |
| 8 | 移动端生成/下载工具栏拥挤、占位语被复制、失败轮询不结束 | 响应式工具栏、明确任务进度、恢复进行中任务、图片独立下载及 ZIP、剪贴板降级、错误可见 |
| 9 | Android 忽略全部 TLS 错误、下载链接被 WebView 吞掉 | 正常证书校验，原生下载转外部浏览器，版本统一递增，沿用签名文件构建校验 |

## 资源与发布

继续使用现有文件存储及可用 Redis，控制 HTTP 并发和正文/图片请求大小。部署前备份当前代码、数据与 APK，记录正文和设定摘要。新版本先用隔离目录执行自动回归、真实 HTTP 并发、前端脚本及浏览器检查，再提交推送 GitHub。发布仅替换本项目文件并重启 novel-hub，核验现有其他业务、生产读取、鉴权、桥接心跳、APK 版本和文件摘要。失败时恢复备份。
